# 《明锜天眼》总大纲（72 集 · 六季）

> **结构**：6 季 × 12 集 = 72 集（Seedance 动画剧本分镜体，每集 7-10 分钟）
> **主线**：废柴少年明锜觉醒天眼 → 看见物质本质 → 看懂宇宙算法 → 创造科技文明 → 归零超越 → 把全人类带向人人修真时代
> **六季递进**：看见 → 理解 → 超越 → 创造 → 法器 → 归零
> **创作原则**：不强行关联、只陈述事实、把握不准不提；每集至少一个小爽点、章末必设钩子；台词避免空洞口号，必须有物理/修行落点
