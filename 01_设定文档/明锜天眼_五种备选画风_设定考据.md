# 明锜天眼 · 五种备选画风 · 设定考据

> **设定考据卡 · 画风线（5种备选风格 + 英文提示词 + 分季映射）**
> 来源：量子探险画风参考页（用户选定）+ AI动漫行业主流画风
> 用途：为《明锜天眼》漫剧/动画选定画风。**不是全剧统一一种，而是按季/场景切换。**
>
> 🎨 **主风格已定：5c「宇宙灵性风」**——它的视觉特征（地球在手中发光、能量场、星座、星盘、万物互联）就是《明锜天眼》的核心视觉：人心是镜子、SEG从虚空取能、七级浮屠。**全剧以宇宙灵性风为基底，其余四种作为场景切换的辅助风格。**

## 二、每种风格的完整定义 + 英文提示词（直接用于AI生成）

### 风格1：2D日漫·清新唯美赛璐璐（主风格）

**中文定义**：高水准现代2D日系赛璐璐，画面线条清晰、色块分明，经典日系动漫视觉。

**英文提示词**：
```
high quality 2D Japanese anime, cel shading, clean lineart, flat colors,
crisp outlines, modern anime style, detailed character, vivid composition
```

**小说适配场景**：第1季天眼初开（明锜觉醒）、第4季AHCS觉醒（实验室日常）、法器实体化。**这是全剧的"基底风格"**——大多数镜头用它，保证统一。

---

### 风格2：2D日漫·清透唯美夏日治愈

**中文定义**：充满通透感与生命力的二次元画风，色彩明亮清新，轻松温暖治愈。

**英文提示词**：
```
healing anime style, translucent bright colors, fresh summer atmosphere,
soft daylight, warm and gentle, vibrant yet soothing, life-like glow,
airy and clean, wholesome mood
```

**小说适配场景**：明锜与静慈的夫妻情、与阿丙的师徒情、法器学院的日常、城市共修大会、第72集服空时代（金色星球、蛋形住宅、孩子赤脚草地）。

---

### 风格3：唯美韩漫

**中文定义**：唯美画风、精致细节、浪漫氛围，人物美型精致，色彩柔和有层次。

**英文提示词**：
```
Korean manhwa style, beautiful aesthetic, delicate detailed characters,
romantic atmosphere, soft layered colors, elegant faces, refined features,
graceful composition
```

**小说适配场景**：人物情感特写（超度时的回望、道歉戏、泪如雨下的将领）、法器纪元的庄严仪式。

---

### 风格4：新海诚风

**中文定义**：清新日系，都市青春故事，极致光影、写实唯美风景（天空、云朵、阳光）。

**英文提示词**：
```
Makoto Shinkai style, breathtaking sky and clouds, dramatic lighting,
urban youth atmosphere, photorealistic beautiful scenery, sun rays,
detailed cloudscape, cinematic color grading
```

**小说适配场景**：第2季从晶格到ANU（都市科学实验室）、第3季零点能时代（城市夜景、万家灯火、高压铁塔退役后的天际线）、空镜头转场。

---

### 风格5：梦幻神圣光效（Angelcore·第五张图）

**中文定义**：充满神圣女性、柔和光晕、粉紫蓝渐变色调的奇幻场景。四个子方向：

**5a·天使核 Angelcore**：
```
angelcore, ethereal, divine beings, soft glowing light, golden hour,
pastel colors (lavender, peach, cream), god rays, holy atmosphere,
translucent silk, floating, peaceful
```

**5b·梦幻厚涂治愈**：
```
dreamy fantasy art, healing atmosphere, soft blended colors, magical girls,
glowing particles, heart-shaped light, serene, masterpiece, best quality
```

**5c·宇宙灵性风（最契合《明锜天眼》核心）**：
```
visionary art, cosmic energy, spiritual connection, glowing earth in hands,
universe, astral plane, bioluminescence, intricate details, fantasy illustration
```

**5d·吉卜力奇幻**：
```
Studio Ghibli style, Hayao Miyazaki, magical creatures, spirit world,
lush nature, warm and healing, detailed background, watercolor texture
```

**小说适配场景**：第5季法器纪元（超度怨灵升入佛国）、第6季层级征服（佛国世界、极乐国土、服空时代的地球如金色星球）。**这是全剧的"高潮风格"**——只在灵性升华的时刻用，形成反差。

## 四、角色一致性铁律（跨风格通用）

无论用哪种风格，**同一角色必须锁定同一张脸**：

1. 每个角色先用**主风格「宇宙灵性风」**生成一张**三视图**（正面/侧面/背面 + 脸特写）作为"锚定图"
2. 所有镜头用这张三视图做图生图/图生视频的参考
3. 换辅助风格时，用同一张三视图 + 风格提示词重绘，保持五官不变
4. 主角明锜、静慈、阿丙、苏晶、萧衍五个人，每人建一个"角色风格档案"

## 五、给《明锜天眼》的一句话建议
